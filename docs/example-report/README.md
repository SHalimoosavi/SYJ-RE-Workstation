# Example report

The compatibility workflow builds a disposable, minimal APK fixture during each CI run and exercises the analyzer against it. The workflow does not commit a third-party APK or an APK binary to this repository.

A real report generated by the workflow is not committed by this change because GitHub Actions artifacts are produced only after the workflow runs. Once the matrix completes, the report artifact can be reviewed and a sanitized copy can be added here in a follow-up commit. This directory intentionally does not present fabricated report output as a real run.
