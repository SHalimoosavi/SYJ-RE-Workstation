Project principles

  • Evidence over verdicts: tool output is evidence to interpret, not a final security conclusion.
  • Static by design: the current workflow does not execute APKs or perform runtime instrumentation.
  • Clear boundaries: GitHub-hosted container checks are not Android or Termux device validation.
  • Honest scope: planned features are labelled planned, not shipped.
  • Responsible use: assess only APKs you own or have explicit permission to inspect.
