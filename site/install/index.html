DOCUMENTATION / INSTALL

Install SYJ-RE-Workstation

Set up Bash tools in Debian-compatible Linux. A provisional Termux + Debian PRoot guide is provided, but device-side compatibility is unverified.

The first public release target is v0.1.0 and has not yet been published.

Runtime requirements

The analyzer requires Bash, file, sha256sum, unzip and AAPT. apksigner and JADX are optional. APKTool is installed in CI for package/tool checks but is not invoked by the analyzer. Debian bootstrap installs YARA and binutils; the analyzer does not run YARA or inspect ELF/native binaries.

Termux on Android

Install Git and PRoot-Distro, then clone:

pkg update
pkg install -y git proot-distro
git clone https://github.com/SHalimoosavi/SYJ-RE-Workstation.git
cd SYJ-RE-Workstation

Optional helper:

bash scripts/termux-bootstrap.sh

Create an APK input directory, install Debian and mount both directories:

mkdir -p "$HOME/rea-input"
proot-distro install debian
proot-distro login debian --bind "$HOME/SYJ-RE-Workstation:/mnt/syj-re" --bind "$HOME/rea-input:/mnt/apk-input"

Inside Debian:

bash /mnt/syj-re/scripts/debian-bootstrap.sh

Use termux-setup-storage only when APKs are stored in Android shared storage. Bind the actual Termux-side input directory.

Debian / Ubuntu

git clone https://github.com/SHalimoosavi/SYJ-RE-Workstation.git
cd SYJ-RE-Workstation
sudo bash scripts/debian-bootstrap.sh

The bootstrap installs base utilities only. It does not install AAPT, apksigner, APKTool or JADX. AAPT is required.

JADX Java runtime

JADX v1.5.6 requires a 64-bit Java runtime 11 or newer. Release-specific commands documented by the project:

DistributionCommandRuntime
Debian 12sudo apt-get install -y openjdk-17-jre-headless17
Debian 13sudo apt-get install -y openjdk-21-jre-headless21
Ubuntu 22.04sudo apt-get install -y openjdk-11-jre-headless11
Ubuntu 24.04sudo apt-get install -y openjdk-21-jre-headless21

See the full tool installation guide. The upstream JADX v1.5.6 ZIP has no published SHA-256 checksum; a local hash does not authenticate the archive.

Compatibility boundary

The compatibility workflow validates GitHub-hosted Debian/Ubuntu amd64 containers only. It does not test physical Android devices, Termux itself or Debian PRoot on Android. Termux and Debian PRoot remain unverified until reproducible community reports are submitted and reviewed.

EnvironmentResult
Debian 12 BookwormPassed
Debian 13 TrixiePassed
Ubuntu 22.04 JammyPassed
Ubuntu 24.04 NoblePassed

These are container-image tests, not device-side validation.
