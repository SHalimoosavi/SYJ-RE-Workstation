HELP / FAQ

Frequently asked questions

Practical answers about scope, tools, compatibility and reports.

What does SYJ-RE-Workstation do?

SYJ-RE-Workstation is an early-stage Bash-based workstation scaffold for collecting static evidence from Android APK files. It records file identity, SHA-256, package metadata, permissions, manifest structure and archive inventory. Signature verification and JADX decompilation are optional integrations when their tools are installed. It does not execute APKs or issue a malware verdict.

Does it detect malware or prove an APK is safe?

No. The workstation collects static evidence; it does not provide malware classification, a complete vulnerability scan, exploitability assessment or proof of safety. Permissions, manifest values, signatures and decompiler output require interpretation and independent corroboration. A clean-looking report is not a security certification, and the tool should not be marketed or relied on as one.

Does compatibility CI test Termux or Android devices?

No. The compatibility matrix runs in GitHub-hosted Debian and Ubuntu amd64 container images. It checks package installation, bootstrap, a disposable APK fixture, analyzer regression tests, artifact upload, Bash syntax and ShellCheck. Physical Android devices, Termux itself, Debian PRoot on Android and other CPU architectures are outside this CI coverage.

Do I need Android root access?

No Android root access is required for the documented Termux plus Debian PRoot workflow. PRoot provides a Linux userspace without rooting the Android device. The Debian bootstrap script runs with root privileges inside Debian, normally the default PRoot-Distro login user; that is not the same as Android device root access.

Which tools are required and optional?

The analyzer requires Bash, file, sha256sum, unzip and AAPT. apksigner enables optional signature verification, while JADX enables optional DEX-to-Java decompilation. APKTool may be useful for manual resource and smali work, but the current analyzer does not invoke it. The Debian bootstrap installs base utilities, not AAPT, apksigner, APKTool or JADX.

Where are reports stored and how do I compare them?

Reports are written under $HOME/SYJ-RE-Workstation/reports/<apk-name>/ by default. Set SYJ_RE_HOME to select another workstation root. To compare two existing reports, run bash scripts/compare-reports.sh with both report-directory paths. The helper compares selected evidence files, reports missing files and suppresses diff exit codes, so inspect its output rather than trusting its final status.
