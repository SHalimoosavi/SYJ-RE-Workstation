DOCUMENTATION / USAGE

Analyze and compare APK reports

Collect static evidence from an APK you are authorized to assess.

Analyze an APK

The analyzer accepts one positional APK path and has no additional command-line flags:

bash scripts/analyze-apk.sh /path/to/authorized-application.apk

Required executables: file, sha256sum, unzip and aapt. It records file identity and size, SHA-256, AAPT package metadata, permissions, manifest tree, ZIP inventory and DEX/native-library paths. If installed, it also runs apksigner and jadx --no-res.

Change the workstation root:

SYJ_RE_HOME="$HOME/re-lab" bash scripts/analyze-apk.sh /path/to/authorized-application.apk

Reports default to $HOME/SYJ-RE-Workstation/reports/<apk-name>/.

Compare two reports

bash scripts/compare-reports.sh /path/to/report-A /path/to/report-B

It compares badging.txt, permissions.txt, dex-and-native-libraries.txt and signature.txt. Missing files are reported. The helper continues through all four comparisons and suppresses diff's non-zero status; zero exit status does not mean reports are identical.

Read the evidence

Start with REPORT-INFO.txt, file.txt and sha256.txt. Review badging.txt, permissions.txt and manifest-tree.txt. Use archive-files.txt and dex-and-native-libraries.txt for archive inventory. If available, inspect signature.txt, jadx-status.txt and jadx.log.

A successful run means collection steps completed; it does not mean an APK is safe. Signature errors are warnings; a non-zero JADX exit is recorded separately.

Limits

  • No malware verdict or safety certification.
  • No APK execution or dynamic instrumentation.
  • No ELF/native binary parser or YARA scan.
  • APKTool is not invoked by the current analyzer.
