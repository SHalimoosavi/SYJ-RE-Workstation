# Contributing

1. Open an issue describing the problem or proposed feature.
2. Keep changes small and reproducible.
3. Run `bash -n scripts/*.sh` before submitting.
4. Test on a disposable sample APK that you are authorized to use.
5. Do not include APKs, credentials, generated reports or proprietary application source.
6. Include tool versions and sanitized logs when reporting compatibility issues.

Contributions should preserve the project's static-analysis-first and privacy-by-default approach.
